## 📸 Image Naming Convention

### **Exact Format:**
```
{brand}-{model}-{view}.jpg
```

### **Rules:**
1. **Lowercase only** - No uppercase letters
2. **Hyphens only** - Replace spaces with hyphens (-)
3. **No special characters** - Remove @, #, $, %, etc.
4. **View suffixes** - Must end with: `-front.jpg`, `-back.jpg`, `-side.jpg`, `-connector.jpg`

### **Examples:**

| Brand | Model | Front View | Back View | Side View | Connector View |
|-------|-------|------------|-----------|-----------|----------------|
| NMB | 2408VL-55W-B79 | `nmb-2408vl-55w-b79-front.jpg` | `nmb-2408vl-55w-b79-back.jpg` | `nmb-2408vl-55w-b79-side.jpg` | `nmb-2408vl-55w-b79-connector.jpg` |
| San Ace | 9WF0424H6503 | `san-ace-9wf0424h6503-front.jpg` | `san-ace-9wf0424h6503-back.jpg` | `san-ace-9wf0424h6503-side.jpg` | `san-ace-9wf0424h6503-connector.jpg` |

## 🎯 Step-by-Step Guide for Each Model

### **Step 1: Identify Brand and Model**
Check your product data or the fan label to get:
- **Brand**: e.g., "NMB", "San Ace", "SUNON"
- **Model**: e.g., "2408VL-55W-B79", "9WF0424H6503"

### **Step 2: Take or Create 4 Photos**
For each fan model, you need 4 photos:

**📷 Front View:**
- Angle: Straight on, facing the camera
- Show: Front face with blades visible
- Include: Fan label, front casing details

**📷 Back View:**
- Angle: 180° from front view
- Show: Back side with motor/connector
- Include: Motor housing, mounting holes, back label

**📷 Side View:**
- Angle: 90° from front view
- Show: Side profile showing thickness
- Include: Fan thickness, frame profile

**📷 Connector View:**
- Angle: Close-up of connector area
- Show: Wire type, connector pins, housing
- Include: Detailed connector information

### **Step 3: Edit and Resize Images**
**Recommended settings:**
- **Format**: JPG/JPEG
- **Resolution**: 400x400px minimum (800x800px recommended)
- **Quality**: High (80-100%)
- **Background**: White or transparent
- **File size**: Under 200KB each

**Tools you can use:**
- Windows Paint (basic resize)
- Photoshop (professional)
- GIMP (free, professional)
- Online tools like TinyPNG or Squoosh

### **Step 4: Name the Files Correctly**

**Conversion Example:**
```
Original: NMB 2408VL-55W-B79
Step 1: Convert to lowercase → nmb 2408vl-55w-b79
Step 2: Replace spaces with hyphens → nmb-2408vl-55w-b79
Step 3: Add view suffix → nmb-2408vl-55w-b79-front.jpg
```

**For each view:**
- Front view: `nmb-2408vl-55w-b79-front.jpg`
- Back view: `nmb-2408vl-55w-b79-back.jpg`
- Side view: `nmb-2408vl-55w-b79-side.jpg`
- Connector view: `nmb-2408vl-55w-b79-connector.jpg`

### **Step 5: Save in the Correct Location**
**Save path:** `D:\Projects\global-cnc\images\models\Driver-Cooling-Fan\`

**Windows:**
1. Click "Save As"
2. Navigate to `D:\Projects\global-cnc\images\models\Driver-Cooling-Fan\`
3. Enter the exact filename
4. Click "Save"

### **Step 6: Test**
1. Open your website: `product-details.html?id=cnc-014`
2. Click on the fan model
3. Check if all 4 images display in the 2x2 grid
4. Click on each image to test zoom functionality
5. Open browser console (F12) to check for any errors

## 🔧 Common Naming Mistakes to Avoid

### ❌ **Wrong:**
- `NMB-2408VL-55W-B79-FRONT.jpg` (uppercase)
- `nmb 2408vl 55w b79 front.jpg` (spaces)
- `nmb_2408vl_55w_b79_front.jpg` (underscores)
- `nmb-2408vl-55w-b79-front.png` (wrong format)
- `nmb-2408vl-55w-b79.jpg` (missing view suffix)

### ✅ **Correct:**
- `nmb-2408vl-55w-b79-front.jpg` (lowercase, hyphens, correct suffix)
- `san-ace-9wf0424h6503-back.jpg` (follows all rules)
- `sunon-pmd2404pqb1-a-connector.jpg` (includes hyphens in model name)

## 🔍 Troubleshooting

### **Images not showing:**
✅ **Check:** File names match exactly (case-sensitive)  
✅ **Check:** Images are in `images/models/Driver-Cooling-Fan/` folder  
✅ **Check:** File format is JPG (not PNG or other)  
✅ **Check:** No typos in file names  
✅ **Check:** Browser cache cleared (Ctrl+F5)

### **Only some views showing:**
✅ **Check:** All 4 view files exist for that model  
✅ **Check:** Naming convention matches exactly  
✅ **Check:** File paths are correct

### **Zoom not working:**
✅ **Check:** Images load correctly in the grid first  
✅ **Check:** JavaScript console for errors (F12)  
✅ **Check:** Click on image triggers zoom modal  
✅ **Check:** Image path is correct in zoom modal

### **Images too large/small:**
✅ **Check:** Resize to recommended dimensions  
✅ **Check:** Aspect ratio is 1:1 (square)  
✅ **Check:** Optimize file size
